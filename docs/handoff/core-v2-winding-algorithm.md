# Алгоритм намотки V2

Исполняемый текст: `play/core-v2/winding.js`. Не фазы кухни, не `kappa`.
Один проход: коробка ядра → рис как кольцо с сохранением площади → нори снаружи
→ остаток листа = клапан шва.

## Вход

Лист `L`, рис на `[sRice0, sRice1]` (hoso: 0,048L … 0,88L), толщина риса `T`,
нори `W`. Начинка не крутится: сидит в коробке `(Wc, Hc)` в покое.

Режим намотки — поле рецепта `winding`, не эвристика по длине начинки
(легаси #141 так переключал кольцо → спираль и путал маки с узумаки).

| `winding` | кухня | V2 alpha |
|---|---|---|
| `ring` | хосомаки, футомаки, чумаки | считает |
| `spiral` | узумаки, датемаки | `unsupported` |
| `inverted` | урамаки | `unsupported` |

Кадзари и нори-двойная — вложенные кольца, не новый `winding`. Тэмаки — не цилиндр.

## 1. Коробка ядра

Пустой хосомаки: `Wc=5`, `Hc=7,2` (каталог). С начинкой коробка обрастает
патчем; один патч — в начале координат, несколько — `u` окна в мм как есть
(`x = u − середина окна`). Это не соседняя перекладка и не сжатие в ±10 мм.

По лучу `φ` внутренний край риса — прямоугольник в полярных:

```
r0(φ) = min( (Wc/2) / |cos φ|, (Hc/2) / |sin φ| )
```

На грани ближе к центру, на углу дальше. 1440 лучей.

## 2. Рис — спираль в кольце площади `T × Lrice`

Внешний край риса — круг, иначе широкая начинка даёт гантель:

```
rp = √( (Wc·Hc + T·Lrice) / π )
```

Внутри этого круга рис — **лента длины Lrice**, не заливка:

```
r̄ = (⟨r0⟩ + rp) / 2
витки = Lrice / (2π r̄)
шаг  = (rp − ⟨r0⟩) / витки    ≈ T
```

Хосомаки ~1,5 витка риса, шаг ≈ 7 мм. Нори снаружи один оборот + клапан
(#111: нори не крутят спиралью). Спираль ленты кончается на `rp` — на
внутренней стороне нори, не в ядре.

Архимедова лента толщины T без сжатия даёт хосомаки ⌀ 39 мм и нори короче
обхвата на 18 мм — это #132, поэтому конверт площади кольца остаётся.

## 3. Лист → цилиндр

```
u(φ) = sRice0 + Lrice · (φ / τ)     // fromUZero
```

Обратный ход `u → φ` должен сойтись (`maxRoundTripErrMm`). Дуги риса и нори
считаются **отдельно** по средней линии слоя, сетка в 4 раза чаще ядра
(erratum-010/013/021). Не копировать `ds` нори в рис.

## 4. Шов

Голый нори: `Lbare = L − Lrice`. Хватает, если периметр средней линии нори
`≤ L`. Угол клапана `φOverlap = Lbare / Ravg`. Бины `[0, overlapBins)` —
два слоя нори.

## Что это не умеет

| кухня | V2 |
|---|---|
| 土手 (края выше) | константа `T`, равномерный `Δ(r²)` |
| ガチャン (один cinch) | нет |
| три пальца → квадрат | коробка ядра, снаружи — овал из `rp` |
| нори после смыкания риса | нори сразу `+W` |
| рис не плющить | площадь сохраняется, форма — нет |

Пока 土手 нет, «алгоритм намотки» — это **раздача площади кольцом вокруг
неподвижной коробки**. Для хосомаки ⌀ этого хватает. Для футомаки щель ядра
лечится масштабом окна, не этой формулой.
