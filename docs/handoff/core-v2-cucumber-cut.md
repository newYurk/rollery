# Нарезка огурца для каппамаки

Не общий справочник 23 приёмов. Только 芯 хосомаки. Источники:
sirogohan, oisiiryouri, 寿司職人Yoshi, 築地すしOmakase, DelishKitchen.

## Порядок

1. **Выбрать прямой.** Кривой не ляжет 芯ом.
2. **板ずり.** Соль, катать по доске, смыть. Цвет, шипы, чуть влаги.
3. **色出し (кайсэки, не все суши-я).** 4–5 с кипятка, лёд. Yoshi показывает 板ずり
   без этой варки.
4. **Хвосты и горькая кожура у ヘタ.** Тело **не чистят** — зелень должна быть на срезе.
   築地: отдельный урок «ヘタの皮剥き».
5. **Вдоль, число долей по толщине плода.**
   - тонкий японский: 4 (DelishKitchen: 1 плод → 4 ролла)
   - обычный: 6–8 (sirogohan: 1 плод → 6–8 хосомаки)
   - 「太すぎるとまきづらいので、細めにまっすぐに」
6. **種を取る.** Семена — вода; вода рвёт нори спустя час
   (築地 「種があると水分で時間が経つと海苔が割れやすくなる」).
7. **Вытереть.** Один стержень на ролл, длина ≈ ширина нори (~19 см).

После шага 6 это уже не полный сектор плода: две плоскости реза + дуга кожицы,
семенное гнездо вынуто. Ближе к палке с одной зелёной гранью, чем к «пицце» ⌀28/8.

## Что это не есть

| рез | куда |
|---|---|
| 拍子木 7–8 мм | 鉄火, тунец, не огурец |
| 千切り / 細切り | другой ролл, пучок в одном хосомаки |
| 小口切り | вариант 鈴木登紀子, не 鉄砲 |
| лента пилером | кадзари |

Классика: **один** стержень. Несколько стружек — 細切り, отдельный профиль.

## 細切り в ядре

Не шесть overlapping cucumber (F07 это `invalid`). Один патч `cut: 'hosogiri'`:
6 палок **3 мм** (середина 2–4 мм), сетка 3×2, зазор 0,4 мм, коробка 9,8 × 6,4.
Площадь = 6 × 3² = 54 мм², не сектор. Чип «細切り» на стенде. F02 сектор не трогали.

## Для ядра

F02 — брусок **8 × 8 мм** после 種取り, кожа с одной грани. Не плотный сектор плода.
細切り — отдельный чип, шесть палок 3 мм. Live `catalog.js` не трогаем.
