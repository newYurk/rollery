# Пол разброса: сколько шумит рука и что метрика вообще различает

Замер 27.08.2026. Раскладка футомаки с четырьмя начинками, сравнение по трём срезам
(v = 0,5 · 0,25 · 0,75) существующей функцией `similarity`. Руки берутся не наугад, а
из **достижимых** диапазонов, которые выдаёт `measureHand` по настоящему жесту:
`press` 0,85–1,30, `air` 0–0,22, `wobble` 0–0,11, `phase` 0–2π.

## Поправка к тому, что говорилось 26.08

Вчера я сказал: «две одинаковые раскладки при разной руке дают среднее 0,74».
**Это неверно для той метрики, по которой считается пазл.** Медиана — **0,962**.

Откуда взялось 0,74: то был строгий поканальный Dice по отдельным начинкам при
вариации прижима. `similarity` же засчитывает попадание по окрестности 3×3, то есть
с допуском примерно в 1 мм, и прижим в этот допуск целиком укладывается. Оба числа
верны, но относятся к разным величинам, и порог пазла надо ставить по второй.

## Вклад каждого параметра поодиночке

Крайнее достижимое значение против нейтральной руки:

| параметр | по начинкам | силуэт |
|---|---|---|
| `press` 0,85 | **1,000** | 0,983 |
| `press` 1,30 | **1,000** | 0,966 |
| `air` 0,22 | **0,686** | 0,797 |
| `wobble` 0,11 | 0,993 | 0,963 |
| `phase` π | **1,000** | **1,000** |

**Весь разброс делает `air`.** Прижим и дрожание не двигают маски вовсе — в пределах
допуска метрики. Воздух между витками меняет шаг спирали, а с ним и взаимное
положение всех начинок по радиусу.

⚑ **Поправка 27.08: `phase` НЕ мёртв — мёртв был мой замер.**

В таблице выше `phase` стоит с 1,000, и я записал его в мёртвые. Это ошибка: фаза
задаёт фазу ДРОЖАНИЯ и включается только при `if (g.wobble)` (`play/index.html:577` на дату замера — номер строки дрейфует, искать по `g.wobble`).
Я крутил её при `wobble = 0`, то есть при выключенном условии.

Перемерено при живом дрожании:

| дрожание | ⌀ при фазе 0 / π / π/2 | разброс |
|---|---|---|
| 0 | одинаково | **0** — условие выключено |
| 0,05 | 53,01 / 53,37 / 53,01 | 0,36 мм |
| 0,11 | 52,81 / 53,59 / 52,79 | **0,78 мм** |

Сходство по начинкам при этом держится 0,996–1,000: маски почти не двигаются, а **силуэт
двигается**. То есть параметр работает ровно там, где и задуман, — в паре с дрожанием.

**Урок общий, не про фазу:** параметр, включённый по условию, нельзя мерить при
выключенном условии. В таблице выше каждый параметр крутился поодиночке при нейтральных
остальных — для `air` и `press` это верно, для `phase` это и обнулило результат.

## Пол разброса: одна раскладка, две независимые руки (24 пары)

| | мин | 10-й проц. | медиана | макс |
|---|---|---|---|---|
| по начинкам | **0,527** | 0,658 | 0,962 | 1,000 |
| силуэт (IoU) | 0,798 | 0,813 | 0,922 | 0,982 |

## Сигнал: сдвиг одной начинки

| сдвиг лосося | та же рука | независимые руки |
|---|---|---|
| 1 мм | 1,000 | 0,927 |
| 2 мм | 0,988 | 0,910 |
| 3 мм | 0,963 | 0,844 |
| 5 мм | 0,820 | 0,719 |
| 8 мм | 0,752 | 0,716 |
| 12 мм | 0,685 | 0,628 |
| 20 мм | 0,675 | 0,561 |
| поменять лосось и огурец местами | **0,534** | — |
| совсем другая раскладка | **0,000** | — |

## Главный вывод: шум перекрывает сигнал

Идеально повторённая раскладка при неудачной паре рук даёт **0,527–0,658**. Ровно
столько же даёт раскладка со сдвигом **12–20 мм**, и столько же — **перепутанные
местами** лосось и огурец (0,534).

То есть при сравнении «как есть» метрика **не отличает верную раскладку с чужой рукой
от неверной раскладки**. Никакой порог этого не чинит: диапазоны наложены.

## Что с этим делать

`S.hand`. Открытый хвост: порог пазла PASS = 0,72 ниже полосы «мимо» — issue #38.)*

**Сравнивать цель, пересобранную РУКОЙ ИГРОКА.** Цель пазла — это раскладка
(`S.puzzle.target`), а не картинка; значит её можно построить заново с тем же `S.hand`,
что был у попытки, и сравнивать две картинки, различающиеся **только раскладкой**.

Это не отменяет решение владельца от 25.08, по которому разброс при одинаковой раскладке
считается авторским стилем: рука по-прежнему меняет то, что игрок **видит**. Она перестаёт менять только
то, как ему **засчитывают**.

## Полосы после уравнивания руки

| полоса | порог | что это значит физически |
|---|---|---|
| **отлично** | ≥ 0,96 | каждая начинка в пределах ≈ 3 мм |
| **принято** | ≥ 0,82 | в пределах ≈ 5 мм |
| **мимо** | < 0,75 | 8 мм и хуже |

Разрешение метрики — около **3 мм**, и это не совпадение: допуск 3×3 на растре 56 px
поперёк ролла ≈ 55 мм даёт примерно 1 мм на пиксель. То есть метрика различает
примерно **одно зерно риса** (3,5 мм) — тот же масштаб, что стоит минимальным
элементом в `docs/inverse-design.md`.

**Порог приёмки inverse design 0,70 — слишком мягкий:** после уравнивания руки он
соответствует ошибке около 12 мм, то есть «начинка не на месте». Поднять до **0,82**.
