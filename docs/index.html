Начать отсюда

  • Ядро: от нарезки до срезастраница · откроется здесь Главный документ. Инженерные схемы всей нашей математики: что такое кусок, что с ним делает скрутка, что показывает срез. Правится вместе с геометрией.
  • Кинематика скруткистраница · откроется здесь Иллюстрированный отчёт: какая модель циновки выжила, откуда взялись толщины, что опровергнуто. Открывается прямо здесь.
  • Архитектурный атласстраница · откроется здесь Четыре листа вместо одного графа зависимостей: что существует, что мешает переезду, один путь от жеста до среза, порядок миграции. Исходники схем — D2, рядом карта для обсуждения в Excalidraw.
  • Свод начинокисходник · GitHub Что кладут в маки на самом деле: канон хосомаки и футомаки, современное и конбини, чем рисуют кадзаримаки. У каждой начинки ДВА облика — вид сверху и срез, они не выводятся друг из друга. И отдельно то, чего в источниках нет.
  • Практика поваровисходник · GitHub Разборы «а как на самом деле»: вдавливают ли начинку в рис, бывает ли спираль, какие сладкие роллы японские. То, по чему сверяется третий сторож.
  • Аудит геометрииисходник · GitHub Толщины по источникам, размер зерна, разбор ошибок в срезе.
  • Аудит честности чиселисходник · GitHub Откуда взялось каждое число модели на самом деле: замерено, выведено или придумано. И одиннадцать мест, где рядом написано не то.
  • Практика поваров: как режут и как кладутисходник · GitHub Разбор японских источников: техники нарезки с миллиметрами, порядок укладки, и почему вдавливать каждый кусок в рис — неверно.
  • Сверка с настоящими макиисходник · GitHub Техника укладки риса, что делают руками, чем это отличается от модели.
