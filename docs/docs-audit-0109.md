Это не просто устаревший абзац: **фигура Ф-2 печатает выноску `фаска R 0.0 мм`** (`piece-body.html:1315–1317`, `r = Math.min(ARRIS, …)` → 0), стоя рядом с прозой «2,2 мм». **A2. Полумесяц: документ описывает снятую формулу. (Строка 334)**

Проза: «у полумесяца — своя дуга `CRESCENT_INNER · √q`».

Код (`geometry.js:277–278`, и дословная копия в самом документе, строки 1099–1102):
```js
top: (d, a) => Math.cos(a * CRESCENT_HALF),
low: (d, a) => CRESCENT_INNER * Math.cos(a * CRESCENT_HALF),
```
`√q` — это профиль **до правки 01.09** («плоские концы, а не острые»). Разница не косметическая: при `√q` низ на краю уходит в ноль, при `cos(15°·a)` он там 0,45·cos15° = 0,4347. Доля тела: старая формула даёт 0,55·π/4 = **0,432**, действующая — **0,5437** (замерено `cutFill`). То есть проза документа описывает фигуру, которая на 26 % «пустее» действующей.

## Что именно стояло на спиральной намотке (прямой ответ на ⚠)

Спираль держит пять мест, и все пять сейчас неверны как утверждения о настоящем ролле: карточка «Число оборотов — это арифметика» (стр. 338–340), карточка «Строгий один оборот — упрощение» (стр. 478–480), строка «Оборотов нори (измерено) 2,94 / 2,53 / 1,97» (стр. 315), подписи «вокруг него спираль» / «нори тонкой непрерывной спиралью» / «нори тоже одной спиралью» (стр. 256, 400, 404) и вывод «сошлось с натурой само» (стр. 474).
