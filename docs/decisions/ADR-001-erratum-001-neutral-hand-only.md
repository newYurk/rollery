# ADR-001, Erratum 001 — в Core V2 только neutral hand

- **Статус:** proposed; действует как обязательное уточнение для реализации до принятия ADR-001.
- **Дата:** 2026-09-03
- **Заменяет в ADR-001:** раздел `Контракт рецепта` в части `RecordedHand`.

## Исправление

Core V2 принимает только:

```ts
type NeutralHand = { mode: 'neutral'; seed: 0 }
```

Поле `RecordedHand` не входит в `RecipeV2`, не передаётся в kernel и не влияет на расчёт среза в V2 alpha.

## Причина

ADR-001 одновременно исключает из V2 реальную деформацию, скольжение и стохастический результат руки и предварительно объявляет `RecordedHand` частью рецепта. Это создаёт неясное обещание: разработчик может начать принимать параметры руки, не имея ни их физического смысла, ни диапазонов, ни fixtures.

## Будущее

Режим руки вводится только отдельным ADR после V2 alpha. Тот ADR обязан определить: какие параметры руки существуют, какие из них действительно изменяют модель, как они сериализуются, что делает seed и какие fixtures гарантируют воспроизводимость. До него V2 обязана отклонять любой hand mode, кроме `neutral`.
