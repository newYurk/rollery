# ADR-001, Erratum 003 — цвет риса свободен, в том числе по диагонали

- **Статус:** proposed; уточняет ADR-001 и Erratum 002.
- **Зафиксировано:** 2026-09-04T01:00Z (владелец, разговор 2026-09-03 вечер EDT).
- **Не отменяет:** Erratum 002. Диагональ **тел** начинки по-прежнему запрещена.
- **Кому:** ревью Core V2 на ветке `architecture/core-v2-foundation`. Перечитать вместе с Erratum 002.

## Решение владельца

Постель риса можно **разукрашивать как угодно**: полоса, диагональ, клякса, буква. Это слой сложных пазлов. Так в жизни делают кадзари цветной шари — не косым тамаго.

Краска — не тело. Высоты нет, намотку не раздувает. Холм цветного риса, который уже вспухает, — снова начинка, не краска.

## Две спирали, их нельзя путать

1. Поле на листе `C(u, v)`.
2. Картинка на срезе `C_srez(r, φ)` — следствие намотки, не отдельная геометрия краски.

Лист: `u ∈ [0, L]` вдоль скрутки, `v ∈ [0, W]` вдоль оси ролла.

Срез в `v = v*`:

```
C_srez(r, φ) = C(u(r, φ), v*)
```

Обратно, для генератора уровня:

```
C(u, v) = C_srez(r(u), φ(u))
```

Kernel только сэмплит поле. Формула спирали живёт в генераторе маски, не в `wind()`.

## Спираль на срезе = полосы по u

`n` рукавов, дискретно:

```
C(u, v) = palette[floor(n * fract(u/L + φ0))]
```

Плавно:

```
t = 0.5 + 0.5 * sin(2π n u/L + φ0)
C = (1-t) c1 + t c2
```

Тонкая нить толщины `w` вдоль витка: цвет нити, если `dist(fract(u/L), α) * L < w/2`, иначе фон.

У хосо/футо (один оборот нори) те же полосы дают **кольца**, не многовитковую улитку. Улитка из двух шари на срезе — узумаки или несколько мини-роллов цветного риса. Одним футомаки из полос по `u` улитку не получить.

## Чтобы узор ехал по ломтикам

```
C(u, v) = palette[floor(n * fract(u/L + k v/W))]
```

`k = 1` — за длину ролла рукав смещается на одну полосу. На тарелке из шести кусков картинка поворачивается. Это диагональ **краски**, не тела.

## Данные, не формула в kernel

Два формата:

1. Рецепт полос — канон и простые пазлы.
   `{ axis: "u", n: 3, phase: 0, colors: ["ivory", "salmon", "ivory"] }`
2. Маска `L × W` в мм или в зёрнах риса. Пиксель = цвет постели. Срез = lookup.

ADR-001: «мазки как первичная сущность — не в V2 alpha; до входа компилируются в Patch[]». Уточнение: **цвет постели — не Patch.** Патч — тело с высотой. Цвет — отдельное поле `rice.color` (рецепт полос или маска). В V2 alpha достаточно однородной постели; поле цвета — следующий ADR после F01–F06, но контракт уже такой.

## Пазл

- цель — картинка среза;
- игрок кладёт прямые тела и красит постель;
- проверка: карта цвета на диске сошла с целью в допуске по зерну;
- генератор: нарисовал спираль/цветок на срезе → протянул назад по `u(r, φ)` → полосы или маска на листе.

## Что ревью не должно смешивать

- свободную краску риса с снятием запрета на `rotationDeg` тел;
- `C(r, φ)` внутри физики намотки;
- обещание «футомаки + полосы по u = улитка из шари».
