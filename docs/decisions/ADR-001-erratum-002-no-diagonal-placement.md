# ADR-001, Erratum 002 — начинка только вдоль оси ролла, диагонали нет

- **Статус:** proposed; обязательное уточнение ADR-001 **до** завершения текущего ревью ветки `architecture/core-v2-foundation`.
- **Зафиксировано:** 2026-09-04T00:50Z (владелец, разговор 2026-09-03 вечер EDT).
- **Заменяет в ADR-001:** поле `Patch.rotationDeg` и любую трактовку «класть как угодно на листе».
- **Кому:** ревьюеру / разработчику Core V2. Если этот файл появился после старта прогона — перечитать контракт рецепта и не предлагать диагональ как фичу V2.

## Решение владельца

Игра и kernel должны быть **ближе к ремеслу**, а не к свободному холсту на листе.

В японской практике маки / кадзаримаки длинную начинку кладут **полосой вдоль оси готового ролла** (на циновке — линия слева направо, длина куска подгоняется под ширину нори). Цель — одинаковое сечение на каждом ломтике. Диагональ на листе — не приём мастера, а косой ролл.

Узор кадзари собирается из маленьких уже свёрнутых роллов и цветного риса, не из поворота одного бруска на 45°. Кадзари по-прежнему вне V2 alpha (ADR-001 «пока не моделирует»).

## Контракт Patch для V2 alpha

```ts
type Patch = {
  id: string
  materialId: string
  uMm: number          // центр вдоль скрутки
  vMm: number          // центр вдоль оси ролла
  widthMm: number      // поперек оси = вдоль u
  lengthMm: number     // вдоль оси ролла = вдоль v; у канона ≈ width нори
  heightMm: number
  placement: 'embedded' | 'surface' | 'stacked'
}
```

- Поля `rotationDeg` **нет**. Ненулевой угол — `invalid: patch_rotated`.
- Тело — призма вдоль `v`. Сечение не «едет» от ломтика к ломтику из-за угла укладки.
- Допустимы осевые профили формы (конус клубники, хвост креветки): это изменение толщины вдоль той же оси, не поворот в плоскости листа.
- Короткий кусок, не доходящий до обоих торцов, остаётся законным: он виден не во всех ломтях, но ось куска всё равно ось ролла.

## Что ревью **не** должно рекомендовать

- оставлять `rotationDeg` в RecipeV2 «на всякий»;
- фикстуры с 45° / поперечным бруском как цель V2 alpha;
- 3D-сшивку ломтиков из-за диагонального тела — такого тела в домене больше нет;
- путать «поперёк на циновке» (это канон: полоса слева-направо = вдоль оси ролла) с «поперёк оси ролла» (это запрещённый поворот).

## Следствие для симулятора

2D-сечение по `v` достаточно для V2 alpha и для офлайн-референса: соседние ломтики не сшивает диагональное тело. Связь по `v` нужна только если появится осевой профиль толщины, не из-за угла укладки.
