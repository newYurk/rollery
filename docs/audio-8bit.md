# 8-битная музыка: чем делаем

Инструмент для саундтрека — MCP-сервер **8-bits-music-mcp** в Claude Desktop.
Установлен 30.08.2026, проверен рукопожатием (сервер отвечает, tools отдаёт).

## Установка (уже сделана, здесь — чтобы повторить на другой машине)

Нужен Node ≥ 18 (стоит v20.19.0). В `~/Library/Application Support/Claude/claude_desktop_config.json`
добавляется ключ `mcpServers` — **не заменяя остальной файл**, там лежат личные настройки:

```json
"mcpServers": {
  "8bits-music": { "command": "npx", "args": ["-y", "8-bits-music-mcp"] }
}
```

Дальше — перезапустить Claude Desktop, в интерфейсе появится значок сервера.
Пакет: `8-bits-music-mcp`, MIT, без API-ключей; `npx -y` тянет свежую версию сам.
Перед правкой конфига делается копия `*.bak-ГГГГММДД-ЧЧММСС` — файл общий с приложением.

## ⚠ Что он умеет НА САМОМ ДЕЛЕ (проверено 30.08.2026)

**Экспорта в этом пакете нет.** `WAVExporter.export` (`@zwitterkaneda/8bits-music-audio-engine`,
`dist/exporters/WAVExporter.js`) целиком выглядит так: подождать секунду и вернуть
`success: true` с сообщением «WAV file exported successfully» и `fileSize: 1024*1024` —
придуманным числом. Файл не создаётся, синтеза нет вовсе. Сервер честно принимает ноты,
считает длительности и отдаёт описание трека — но звука не производит.

Проверено прямым вызовом по stdio: четыре инструмента отвечают, `export_audio_composition`
рапортует успех, файла на диске нет. Так что как **источник звука он не годится**; как
помощник по музыкальной теории (аккорды по ступеням, ритмические рисунки) — сгодится.

**Звук делаем своим синтезатором:** `tools/chiptune.py` — импульсная волна для мелодии,
треугольник в басу (как третий канал NES), арпеджио вместо аккордов, шумовой канал для
перкуссии. Он в репозитории, правится и воспроизводим:

```bash
python3 tools/chiptune.py ~/Desktop/rollery-theme.wav
afconvert -f m4af -d aac -b 128000 ~/Desktop/rollery-theme.wav ~/Desktop/rollery-theme.m4a
```

Второй строкой — перевод в m4a: айфон играет и WAV, но m4a вчетверо легче (0,4 МБ против 2,1).

## Что заявлено в описании пакета

Сочинение мелодии и ритма, волны NES-типа (square / triangle / noise), темп и тональность,
экспорт в **WAV** и **MIDI** (последнее — см. оговорку выше). Запрос даётся словами, например:

- «retro game theme, catchy melody, 140 BPM, square wave»;
- «8-bit boss battle theme with drums, export as WAV»;
- «calm exploration theme in C major, triangle waves».

## Правила для «Ролльни»

- **Длительность темы: 13–30 секунд** (решение владельца 30.08.2026). Короче — тема не
  успевает прозвучать, а петля начинает надоедать частотой повтора; длиннее — это уже не
  заставка, ей нужно развитие, которого на четырёх каналах взять неоткуда. Коридор вшит в
  `tools/chiptune.py` (`MIN_SEC`, `MAX_SEC`): файл вне него не пишется, и правится при этом
  партитура или темп, а не порог.

- **Звук в git не кладём.** WAV и MIDI — результат работы, как прогоны симуляции: живут локально
  (`runs/` в .gitignore). В репозиторий идут только исходники и доки. Когда звук понадобится
  показать — один самодостаточный HTML-отчёт или артефакт, а не сто файлов.
- **Стиль ещё не выбран.** Сейчас у игры процедурный звук на месте (`play/audio.js`: шорох
  циновки, стук ножа) — он часть механики, а не саундтрек. 8-битная тема — отдельный слой,
  и браться за неё до полноты механик рано (решение владельца 29.08).
- Идея арт-стиля 16bit/pixel и локальная генерация картинок через Draw Things — соседняя тема,
  тот же принцип: пробы локально, в git — только то, на что ссылается действующий документ.
