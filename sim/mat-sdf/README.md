# mat-sdf — скрутка вокруг настоящей циновки

Пятая атака на референс скрутки. Материалы, солвер (MLS-MPM), растеризация карты классов 600×600 и
метрики взяты из [`../reference/run.py`](../reference/run.py) без изменений. Переписана **только
кинематика** — по «ГЛАВНОЙ ПОПРАВКЕ» в [`../KINEMATICS.md`](../KINEMATICS.md) от 26.08.2026, 12:50:
циновка не дуга сверху, а лист, который лежит **под** нори с самого начала и заворачивается **вместе
с роллом**.

Способ: циновка — **движущаяся гибкая граница, заданная аналитически**. Не цепочка частиц, не
оболочка: параметрическая кривая, у которой во времени меняются длина завёрнутой части и положение
точки контакта.

Запуск:

```bash
cd sim/mat-sdf && source ../.venv/bin/activate
python run.py --layout 4 --grid 240 --particles 16000 --frames 12
```

## 1. Как устроена циновка

### Кривая

В каждый момент циновка состоит из двух кусков:

* **плоского** — впереди точки контакта (`x > xc`) она лежит на столе и совпадает с ним;
* **завёрнутого** — дуги окружности радиуса `R`, касающейся стола в точке `(xc, 0)`.

Угол `th` отсчитывается **по часовой стрелке от точки контакта**: `th = π/2` — сзади ролла,
`th = π` — сверху, `th = 3π/2` — спереди.

```
P(th) = ( xc − R·sin th ,  ylift + R·(1 − cos th) ),     th ∈ [0, Φ]
```

Нори лежит на **вогнутой** стороне, поэтому связь односторонняя: «оставаться внутри». Это ровно тот
же контакт с трением, что был в `reference` (`MU_MAT = 2` — прижатая циновка практически липкая),
только геометрия другая: круг вместо архимедовой спирали и дуга снизу вместо шапки сверху.

### Качение без проскальзывания

Точка контакта идёт по столу и по самой циновке с одной скоростью:

```
d(xc)/dt = d(s_c)/dt = v
```

где `s_c` — длина циновки, прошедшая через точку контакта. Отсюда материал циновки с дуговой
координатой `s` сидит на угле `th = (s_c − s)/R`, а завёрнутый угол растёт сам:

```
Φ = s_c / R
```

Скорость границы — поле твёрдого качения (плюс радиальный член меняющегося `R`):

```
v_mat(th) = ( v·(1 − cos th) − Ṙ·sin th ,  Ṙ·(1 − cos th) + v·sin th )
v_mat(0)  = 0        — на столе циновка не скользит
v_mat(π)  = (2v, 0)  — верх идёт вдвое быстрее центра
```

**Два следствия, ради которых всё и делалось:**

1. Ближний конец циновки описывает **циклоиду**, и радиус сгиба листа равен `R` **везде**. Складка
   мельче `R` невозможна по построению. Собственный минимальный радиус изгиба циновки
   (`R_MAT_MIN = 0.5 T`, бамбуковые палочки 2–3 мм при `T ≈ 5 мм`) в прогонах ни разу не был
   ограничивающим: рабочий `R` — от 1.68 до 4.3 T.
2. **Свободного пролёта листа нет ни в один момент.** Нори либо плоско на столе, либо на дуге. Это
   и есть то, что прежняя модель (точечный захват края через воздух) теряла и что порождало
   «гармошку».

### Радиус

`R = R_b + e_R`, где `R_b` — геометрическая база, `e_R` — поправка регулятора давления.

**Первый оборот** — радиус задают руки, регулятор выключен (`e_R = 0`). Круг должен вместить стопку
начинок плюс полость от сгиба, внутри стенки толщиной в один лист `h = T + w = 1.12`:

```
R_fold = max( R_MAT_MIN + h ,  h + √( a_fold/π + (CORE_HOLLOW·h)² ) ,  h_top/2 + FOLD_CLEAR )
CORE_HOLLOW = 0.5,  FOLD_CLEAR = 0.8
```

**Дальше** — архимедова спираль: каждый следующий оборот добавляет одну толщину листа,

```
dR/ds = h(s)·(1 + PACK_AIR) / (2πR)     ⇔    R² += h(s)·(1 + PACK_AIR)·ds / π
```

`h(s) = T + w` под рисом и `w` над голым клапаном последних 5 T. `PACK_AIR = 0.04` — витки никогда
не укладываются идеально; без этой поправки геометрическая спираль равна радиусу **недеформированной**
площади, и циновке приходится сжимать рис ровно на объём воздуха между витками (замерено:
сохранение падало до 0.945).

Регулятор давления `e_R` получает право голоса с паузы: `[−0.35, 0]` на паузе (только уплотнять),
`[−0.5, +0.05]` при качении — наружу почти не пускаем, иначе весь запас придётся выжимать финальному
обжиму, а нерастяжимая обёртка умеет укорачиваться только складками.

### Вывод переднего края

При качении `Φ` ограничен сверху так, чтобы передний конец циновки шёл **над** тем, что ещё лежит
впереди, а не подгребал его:

```
Φ ≤ φ_land(R, y_ahead + FRONT_CLEAR),  где  φ_land(R, y) = 2π − arccos(1 − y/R)
```

`y_ahead` — **замеренная** (98-й перцентиль в полосе `x ∈ [xc + 1.05R, xc + 2.6R]`, со скоростью
слежения 0.5 T за единицу времени) высота того, что впереди: над постелью это ≈ 1.12, над голым
клапаном — 0.12, и циновка тогда закрывается почти на полный круг и **прижимает клапан к роллу**,
вместо того чтобы прокатиться по нему. Это и есть «передний край постепенно выводится из-под ролла».

### Пальцы (`--fingers`)

Вторая кинематическая опора первого оборота: крышка над той частью стопки начинок, до которой ролл
ещё не докатился, плюс тормоз на её сползание вперёд.

```
x ∈ [ xc + 1.05·R , s_fold + 0.5 ],  y > h_top + 0.12
   →  vy = min(vy, 0);  vx *= exp(−3·fingers·dt)
```

Начало полосы `xc + 1.05R` гарантированно вне следа дуги (`x ∈ [xc − R, xc + R]`), так что пальцы и
циновка никогда не спорят за один узел. Отпускаются в момент смыкания риса.

## 2. Фазы и тайминги

| # | Фаза | Что происходит | Условие конца | Ручка |
|---|---|---|---|---|
| 1 | `lift` | ближний конец циновки идёт вверх по задней стороне и через верх; нори едет на ней; пальцы держат начинку | `Φ ≥ π` | `--speed` |
| 2 | `close` | конец доводится вниз, ближняя линия риса встречается с дальней поверх начинок | `Φ ≥ φ_meet` | `--tuck` |
| 3 | `hold` | качение стоит, циновка давит сильнее (×1.6), пальцы отпускают | пауза `6·hold` | `--hold` |
| 4 | `roll` | циновка катится вперёд вместе с роллом, `R` растёт по спирали, передний край выводится | впереди ничего дальше `0.55R` и лист израсходован | `--speed`, `--press` |
| 5 | `ring` | циновка смыкается в кольцо вокруг всего, включая клапан | `T_CLOSE = 6` | — |
| 6 | `press` | обжим по кругу до силового равновесия при `P_press` (круг; для раскладки 5 — скруглённый квадрат) | равновесие держится `T_CONV = 3` | `--press` |

Угол смыкания:

```
φ_meet0 = φ_land(R_fold, T + w)              — конец садится ровно на дальнюю линию риса
φ_meet  = π + tuck·(φ_meet0 − π)             — --tuck 0.6 недоворот, 1.3 вдавливание
s_close = R_fold · φ_meet
```

Скорость руки идёт к цели с лагом `TAU_V = 1.5`: мгновенная ступенька с 0 на `v_roll` дёргает лист,
пока остальной ролл стоит.

## 4. Что не получилось

**1. Переходный всплеск складок в фазах `ring`/`press` (1–4 штуки, амплитуда до 0.21 T).**
Единственная невязка, оставшаяся от строгой цели «ноль на всех фазах». Механизм понятен и виден по
истории (`wrinkle_hist`): на протяжении всего `lift/close/hold/roll` счётчик ровно 0, и он
подскакивает ровно в тот момент, когда сомкнувшееся кольцо впервые прикусывает ролл. Ролл после
качения не идеально круглый — циновка оставляет спереди-снизу открытый клин, через который заходит
постель, и там ролл слегка выпирает. Кольцо, стягивая выпуклость, укорачивает обёртку по окружности,
а нерастяжимая лента укорачивается только выпучиванием. К концу обжима всё разглаживается
(`wrinkles` в финале = 0). Что пробовалось и не помогло: давление обжима 0.6…2.4 (счётчик не
меняется), скорость обжима 0.12 → 0.06, плотный «gather» (перцентиль 99.8 и запас 0.5 % вместо 3 %).
Что бы сделал дальше: гибкую циновку на фазах 5–6 — кольцо, повторяющее контур ролла, а не окружность.

**2. Плавное смыкание кольца ломает лист.** Пробовал интерполировать за `T_CLOSE` всё сразу — угол
до 2π, радиус до собранного, центр от точки контакта к центру масс ролла. Итог хуже во всех
раскладках: дыры в нори по 4–5 T, `stable = false`. Мгновенная передача (как в `reference`) держится.
Причина не разобрана; откатил.

**3. Кинематическая «приклейка» нори к циновке (`--bond`) выключена по умолчанию — и это результат.**
Задумывалась как гарантия «нори едет на циновке» и была первой рабочей версией. Но она гонит ленту по
жёсткому полю качения циновки, тогда как ролл под ней движется не совсем жёстко, и рассогласование
рвёт ленту: дыры 0.36–0.72 T на раскладках 2 и 4. Двух заплаток (сглаживание веса на концах дуги
`BOND_TAPER`, пропуск того листа, что ещё не прошёл точку контакта, `BOND_LAG`) не хватило. С
`--bond 0` — то есть на одном трении, как и сказано в KINEMATICS.md («нори прижата к ней рисом») —
лист следует за циновкой не хуже, а лента цела. Ключ и код оставлены: `--bond 0.85` воспроизводит
дефект.

**4. Регулятор давления по замеренной длине контакта (`P·L_contact`) сам по себе неустойчив.**
Идея правильная: жёсткая дуга касается некруглого ролла лишь частью пролёта, и если брать давление
по всему номинальному пролёту (соглашение `reference`), регулятор дожимает до локального давления
в 1.5–2 раза выше заданного (замерено `J = 0.91`). Но у замеренной длины две ямы, обе пришлось
затыкать отдельно:
   * поднятое кольцо несёт **собственный вес ролла**, и при контакте в 8 % пролёта вес один
     уравновешивает цель — регулятор останавливался с зазором 0.6 T и объявлял равновесие
     (`R = 5.13` вокруг ролла `Rout = 4.51`). Лечится вычитанием веса (`W_roll`);
   * без монотонности (`Ṙ ≤ 0` на фазах 5–6) тот же вес читается как перегрузка и кольцо
     разъезжается до `R = 7.2`.
   Оба костыля в коде и помечены комментариями. `P_PRESS_REF = 0.04` здесь **не сравним** с 0.08 из
   `reference`: там давление раскладывалось по всему пролёту, здесь — по контакту.

**5. Сохранение массы на раскладке 1 гуляет 0.950–0.961 между прогонами** с одним и тем же кодом.
Разброс от того, в какой момент обжим ловит равновесие (сила шумная, фильтр `tau_f = 1.5`,
`T_CONV = 3`). Порог 0.95 держится, но запаса почти нет. С начинками спокойнее: 0.965 и 0.971.

**6. Число оборотов расходится с формулой площади на раскладках с начинками** (2.61 против 3.13;
2.25 против 2.76), при том что `Rout` совпадает идеально. Формула `crossings = (Rout − Rcore)/h + 1`
берёт `Rcore = √(s_fold·h/π)`, а настоящее ядро первого оборота здесь — `R_fold`, и оно заметно
больше (`crossings_predicted_close` считает именно так и даёт 2.10 и 1.79 — теперь промах в другую
сторону). Ни один из двух вариантов формулы не описывает результат лучше ±0.5. Отдельно: сам счётчик
`nori_turns` = число серий класса «нори» вдоль луча по растру, и он чувствителен к дыркам в растре
тонкой ленты — на раскладке 1 он давал 4.7 и 5.5 в тех прогонах, где лента была порвана. Пока лента
цела (сейчас), он ведёт себя разумно.

**7. Мелочи.** `fold_radius_min_T` (0.13–0.21 T) меряет самый крутой изгиб срединной линии по всей
ленте и на концах ленты ловит артефакт свободного края, а не сгиб — сам сгиб на всех фазах равен
рабочему `R` (1.7–4.3 T). `rice_area_ratio_ref` (0.79–0.92) остаётся растровой оценкой и
систематически занижает; честная мера сохранения — `conservation` по Σ(vol·J), как и записано в
KINEMATICS.md.
