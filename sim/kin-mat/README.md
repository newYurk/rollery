# kin-mat — переработанная кинематика скрутки

Форк `sim/mpm-shell/` (материалы, солвер MLS-MPM, растеризация 600×600 и метрики оставлены как были).
Изменена **только кинематика границы «циновка»** — по спецификации `sim/KINEMATICS.md`, четыре фазы A/B/C/D.
Захвата частиц (kinematic grab по индексам) нет: граница — движущийся SDF, всё остальное делает контакт.

Запуск:

```
R=$(git rev-parse --show-toplevel)   # окружение локальное, в git его нет
source "$R/sim/.venv/bin/activate"
cd "$R/sim/kin-mat"
python run.py --layout 4 --speed 1.0 --press 1.0 --tuck 1.0 --grid 240 --particles 16000 --frames 10
```

Выход в `out/`: `metrics_<tag>.json`, `material_<tag>.png|npy` (карта классов), `final_<tag>.png`,
`particles_<tag>.npz` (x, cls, J, F), `frames_<tag>/fNNNNNNN.png` (весь стол) и `…z.png` (зум на зону контакта).
Один прогон — 21–26 с на M4 Max (CPU, 16 ядер) при `--grid 240 --particles 16000`.

## 1. Геометрия границы

Циновка — **одна** параметрическая кривая на все фазы: архимедова спираль, касающаяся стола в точке
схода `xc`. Обозначения: `R` — радиус у точки схода (силовой контроль, как в `mpm-shell`),
`p` — шаг спирали (pitch), `lift` — подъём кольца над столом (только фаза D), `φ` — угол обхвата.

```
центр      C(t)   = (xc,  R + lift)
радиус     rb(θ)  = R − p·θ/(2π)                        θ ∈ [0, φ]
точка      P(θ)   = C + rb(θ)·(−sin θ, −cos θ)
```

θ отсчитывается от точки схода назад-вверх-через-верх-вперёд:
θ=0 — стол под роллом, θ=π/2 — зад, θ=π — верх, θ=3π/2 — перёд, θ→2π — снова к столу спереди.

Материал обязан оставаться **внутри** (`r ≤ rb`); условие ставится на узлах сетки с
`r − rb ∈ (−0,5·dx, 3·dx)`, нормаль `n = (sin θ, cos θ)`, кулоновское трение `μ_mat = 2`
относительно скорости границы

```
vb(θ) = (v_c, ẏ_c) + Ṙ·(−sin θ, −cos θ) + ( v_t·rb/R − unroll·θ·Ṙ )·(−cos θ, sin θ)
```

- `v_c` — скорость точки схода вдоль стола, `v_t` — скорость протяжки циновки вдоль её собственной длины
  (в фазах A/B они разные, см. ниже), `ẏ_c = Ṙ + d(lift)/dt`;
- множитель `rb/R` делает вращение жёстким (тангенциальная скорость ∝ радиусу), при θ=0 `vb = 0` —
  качение без проскальзывания;
- `unroll = 1` пока циновка ещё разматывается (`φ = s_mat/R < 2π`), иначе 0.

**Почему спираль, а не окружность.** Это и есть главное исправление. Окружность радиуса `R`,
касающаяся стола в `xc`, геометрически пересекает постель толщиной `h = T + W_NORI = 1,12`,
лежащую впереди: нижне-передняя ветвь проходит на высоте `y = R − √(R²−δ²) < h` при
`δ < √(2Rh) ≈ 2 T`. Именно эта ветвь в `mpm-shell` тащила рис вперёд (скорость границы там
`≈ (0,14, −0,21)` — вперёд и вниз), рис сгребался с нори, и в карте оставалось 70 %.
У спирали с шагом `p = h` виток назад от точки схода тоньше ровно на толщину входящего листа,
поэтому нижне-передняя ветвь входит в контакт на высоте `y → p = h` (верх постели) и дальше
только поднимается: при `R = 2,68, p = 1,12` — `y(θ=340°) = 1,13`, `y(315°) = 1,35`, `y(270°) = R`.
Постель **проходит под циновкой**, а подхватывается за точкой схода, где спираль скачком
опускается до `rb = R` (то есть до стола). Контакт с листом впереди — только сверху.

Оставлен и «страховочный» отсечкой-клип (`px > xc + 0,15 и py < y_clear` → контакт пропускается),
но `Y_CLEAR_FOLD = 0`: при шаге спирали он не нужен, геометрия уже гарантирует нужное.

Прессовка квадратом (раскладка 5) — прежний SDF скруглённого квадрата, теперь тоже с центром
`(xc, R + lift)`.

## 2. Геометрия подворота (вход в фазы A/B)

```
зона сгиба: первая начинка стартует ≤ 5 T от края; следующая присоединяется,
            если начинается ≤ 2,5 T после конца предыдущей
s_fold_base = (конец зоны) + 1 T,  не дальше 0,45·L_SHEET;   без начинок = 5 T
s_fold      = tuck · s_fold_base
A_fold      = площадь начинок зоны сгиба
c           = T + W_NORI = 1,12
R_fit       = c + √( c² + A_fold/π )        ← замкнутый подворот: π R² = 2πR·c + A_fold
R_hold      = max( R_fit, (верх стопки + 0,3)/2 )
R_core      = clamp( max( (s_fold − X_MAT0)/2π ,  tuck·R_hold ),  1,25 ,  4,5 )
```

`R_fit` — радиус, при котором петля подворота ровно вмещает то, что в неё заворачивается
(постель длиной в собственный периметр плюс начинки). Тянуть подворот туже нельзя: постель
толщиной 1,12 не гнётся в радиус меньше ≈ 2 без нефизичного сжатия внутренней стороны.
`R_core` служит нижней границей для силового контроллера радиуса весь прогон.

Значения: раскладка 1 — `s_fold = 5,0`, `R_core = 2,24`; раскладка 2 — `4,9 / 2,79`;
раскладка 4 — `11,2 / 3,32` (A_fold = 11,27).

## 3. Фазы и тайминги

| фаза | условие входа | что делает | φ | pitch p | lift | v_c | v_t |
|---|---|---|---|---|---|---|---|
| **A** подъём края | t = 0 | ближний край листа поднимается по дуге | `s_mat/R < π` | 0 | 0 | `λ·v_c` | `v_c` |
| **B** подворот | `φ ≥ π` | край проходит над начинками и ложится за ними | `s_mat/R ∈ [π, 2π)` | 0 | 0 | `λ·v_c` | `v_c` |
| **C** прокатка | `φ = 2π` | качение без проскальзывания, лист входит снизу-спереди | `2π` | `0 → 1,12 → 0,12` | 0 | `v_c` | `v_c` |
| **D** замыкание+прижим | `xc ≥ x_end = 39,7` | сбор, кольцо, прессовка | `2π` | `→ 0` | `→ 0,25` | 0 | 0 |

- `ds_mat/dt = v_c` в A/B (циновку тянут за ближний конец), `dxc/dt = λ·v_c` с
  `λ = clamp( (s_fold − X_MAT0)/(2πR), 0,15, 1 )`. Смысл: точка схода **ползёт**, пока циновка
  протягивается — иначе край приземлялся бы на `2πR ≈ 14 T` впереди, а не на `s_fold`, и
  нижне-передняя ветвь пропахивала бы постель на 1,57·R вперёд (в первых итерациях это давало
  вал риса высотой 2–4 T перед роллом).
- В C шаг спирали = толщине того, что ещё лежит впереди: `T + W_NORI = 1,12` пока
  `xc < 34,3` (конец риса 33,7 + 0,6), затем `W_NORI = 0,12` (голый клапан). Скорость изменения
  шага ограничена `V_LIFT = 0,10`.
- Вход в D: **сбор** — радиус однократно раскрывается до
  `R ← min( R_MAX, 1,25·R, max(R, need + 0,05) )`, где
  `need = P99.9{ ((x−xc)² + y²) / (2y) }` по частицам с `y > 0,35` (радиус окружности, касающейся
  стола и проходящей через частицу). После сбора всё, включая клапан, оказывается внутри кольца.
- В D `p → 0` (спираль схлопывается в кольцо 360°, клапан прижимается), давление
  `P_ROLL → P_PRESS` за `0,35·T_PRESS`, `T_PRESS = 12`. Кольцо приподнимается на `lift = 0,25`,
  чтобы прессовка не выдавливала рис вбок в щель «кольцо–стол».
- Радиусный контроллер как в `mpm-shell`: `F_t = P·R·φ`, `Ṙ = V_RADIAL·clamp((F−F_t)/F_t, −1, 1)`,
  `R ∈ [max(R_MIN, R_core), R_MAX]`.

Фактические времена (раскладка 4, `--speed 1`): A 0→41,7; B 41,7→83,5; C 83,5→197,5; D 197,5→209,5.
Раскладка 1: A 0→28,2; B →56,3; C →195,1; D →207,1.

### Что прошло

- **Кинематика та, что описана в `KINEMATICS.md`.** По кадрам (`out/frames_4/*z.png`):
  t=24 — край поднят по дуге, начинки ещё на столе (A); t=49 — постель с огурцом, тамаго и
  лососем загнута вверх и вперёд, край над начинками (B); t=73 — петля замкнулась вокруг
  всех четырёх начинок, край опускается за ними (конец B); t=121 — ролл катится, лист входит
  снизу-спереди, нори сплошная (C); t≈200 — кольцо, прижим (D).
- **Рис больше не счищается с листа.** За контуром ролла остаётся 0,13–0,38 % частиц риса
  (в `mpm-shell` — заметная куча впереди циновки и `rice_area_ratio = 0,706`).
- **Нори цела**: `nori_max_gap_T = 0,0648…0,0666` при шаге частиц нори 0,049…0,056
  (порог разрыва — 2,5 шага), `nori_torn = false`, в карте одна связная компонента.
- **Устойчивость**: `escaped = 0`, `stable = true`, `v_max_final = 0,14…0,35` (порог 5,0).
- **Раскладка 4: четыре начинки в ядре**, порядок читается, ядро компактное. ⌀ ядра ≈ 5,8 T —
  чуть выше «⌀ ≈ 4,5–5 T», если эта цифра относится к ядру; диаметр *ролла* при сохранении
  площади (45 T² материала) не может быть 4,5–5 T вовсе — он 7,8 T, см. ниже.
- **`--speed`, `--press`, `--tuck` работают в ожидаемую сторону** (см. §6).

### Что не прошло и почему

1. **`nori_turns` 1,2–1,6 — не достигается: 2,39…2,69 (было 3,25).** Это не кинематика, а
   геометрический инвариант. Среднее число пересечений нори лучом из центроида равно
   `(1/2π)∮ ds/r` по кривой нори; для намотки, сохраняющей площадь, с шагом `p` в диске радиуса
   `R` это ≈ `(R − r_ядра)/p + (длина крючка)/(2π r_ядра)`. При `L_SHEET = 38,7 T`, слое риса
   `T = 1` и `R = √(A/π) ≈ 3,4…3,9` результат ≈ 2,3…2,9 **при любой кинематике**: сделать 1,3
   можно только (а) укоротив лист до ≈ 1,3·2πR ≈ 28–31 T, либо (б) допустив в ролле ≈ 35 %
   воздуха. У настоящего футомаки лист 19 см при слое риса 1 см — то есть 19 «своих толщин»,
   а не 38,7; стенд к тому же **обрезает** лишний лист в точке замыкания (`reality-check.md`, п. 5).
   Вывод: чинить надо не циновку, а длину листа/толщину `T` в раскладках — либо сравнивать
   стенд с референсом по обороту нори *после* обрезки.
2. **`rice_area_ratio ≥ 0,90` — не достигается по этому определению: 0,749…0,787.** Разложение:
   `rice_area_ratio_J = 0,90…0,96` — рис уплотнён прессовкой на 4–10 % (это задумано, `--press`);
   ещё ≈ 15 % теряет сама растеризация: диск фиксированного радиуса `0,6·hp` перестаёт покрывать
   плоскость, когда частицы разъезжаются сдвигом (пластика риса), хотя объём сохраняется.
   Контроль: на **начальном** состоянии та же растеризация даёт `rice_map0 = 33,70` при истинных
   33,7 (раскладка 1; в раскладке 4 hp крупнее — 32,57, отсюда `rice_area_ratio_ref = 0,775`) —
   в неподвижном состоянии смещения практически нет, оно появляется только после сдвига.
   Перекрытие штрихом нори — лишь ≈ 1 % (`rice_area_ratio_alone`). Физическая проверка
   «рис не счищается» проходит: `rice_outside_contour_frac ≤ 0,38 %`.
   Попытка растеризовать след частицы по `F` не годится: при пластичности `F` — только упругая
   часть, она не знает о разъезжании.
3. **`tail_outside` — формально не проходит: max превышение 0,40…0,57 T.** Это не «хвост листа»
   (клапан прижат, см. `final_*.png`), а плёнка риса **толщиной в одну частицу**, размазанная по
   столу под нижне-правой частью ролла (φ ≈ −60…−75°), выдавленная на последних 1–2 T прокатки и
   при прессовке: 16…75 частиц = 0,10…0,47 %. При допуске 0,6 T проходят все три раскладки.
   Подъём кольца на `lift = 0,25` в фазе D уменьшил превышение с 0,67 до ≈ 0,5, полностью убрать
   плёнку в рамках «стол = липкая стенка с μ=0,4» не удалось.
4. **Раскладка 4: порядок начинок слева направо не сохранён — он перевёрнут.**
   Было cucumber, tamago, salmon, avocado → стало avocado, salmon, cucumber, tamago
   (чистый разворот дал бы avocado, salmon, tamago, cucumber; cucumber и tamago поменялись
   местами при уплотнении ядра). Разворот — прямое следствие подворота: ближняя половина постели
   ложится **перевёрнутой**, ровно как в модели стенда (`reality-check.md`, п. 2). То есть
   проверка в `KINEMATICS.md` сформулирована неверно: ожидать надо инверсию порядка.

  Механизм читается однозначно, но режим разрушительный.
- `--tuck 1,3` — переворот: самое крупное и самое чистое ядро, хвоста нет вовсе.

## 7. Известные ограничения

- Плёнка риса под роллом (п. 3 выше) — единственный остаток «размазывания»; влияет на
  `tail_outside`, но не на форму среза.
- `rice_area_ratio` в текущем определении смещена вниз на ≈ 15 % в деформированном состоянии;
  для сравнения стенда с референсом лучше использовать `rice_area_ratio_J` +
