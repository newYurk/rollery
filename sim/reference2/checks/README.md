# checks/ — адверсарная проверка reference2 (сохранение и структура)

Проверяются пять требований на раскладках **1, 4, 5**:

1. масса каждого материала `Sum(vol*J)_end / Sum(vol)_start >= 0.97`;
2. ноль вылетевших частиц;
3. обёртка — одна связная лента;
4. ничего за контуром дальше `0.3 T`;
5. начинки не разорваны, изменение площади каждой `< 15 %`.

## Файлы

* `check_conservation.py` — считает все пять **заново из дампов частиц**
  (`out/particles_<tag>.npz`, `out/material_<tag>.npy`), не доверяя `metrics_<tag>.json`.
* `rerun.py` — гоняет `../run.py` **без правок** (импортом, не копией), с опциональной подменой
  одного параметра материала: `--nu <значение>` меняет коэффициент Пуассона риса.

```bash
cd sim/reference2
../.venv/bin/python checks/check_conservation.py 1 4 5              # поставленные прогоны
../.venv/bin/python checks/rerun.py --nu 0.49 --layout 4 \
      --grid 240 --particles 16000 --frames 0 --out checks/adv_out --tag advNU49
R2_OUT=checks/adv_out ../.venv/bin/python checks/check_conservation.py 4advNU49
```

`R2_OUT` — папка с дампами (по умолчанию `../out`). Аргументы — теги как в именах файлов.

## Чем проверка строже метрик run.py

| Требование | Как считает `run.py` | Как считает `check_conservation.py` |
|---|---|---|
| масса материала | `conservation_rice/_nori/_fillings`, флаг `conservation_ok` с порогом **0,95** | то же `Sum(vol*J)/Sum(vol)`, но **по каждому классу отдельно** и с порогом 0,97 |
| обёртка одна лента | `nori_components_map` — 8-связные компоненты растра; соседние витки касаются и **сливаются в одну**, так что 1 получается почти всегда | плюс 4-связность и плюс топологический тест: наибольший разрыв **вдоль ленты** (по порядку `nori_col` внутри решётчатого ряда) в долях шага частиц |
| начинка не разорвана | не считается | компоненты **облака частиц** начинки при пороге связи `2.5*hp` (как `nori_torn` в `run.py`), фрагментом считается кусок от 1 % частиц |
| площадь начинки | `fillings[*].area_T2` = `sum(vol[cls==c])` — **начальная** площадь, без `J` | `Sum(vol*J)` против `Sum(vol)` по классу начинки |
| вылет | `escaped` — счётчик ударов о стенку домена 50x13 T | плюс проверка `finite`, `J > 0` и физический вылет: частицы за контуром + 0,3 T, с разбивкой по классам |

Растр красит нори **последней** (`run.py`, `rasterize`: `order = [RICE] + fillings + [NORI]`), поэтому
виток нори режет начинку на карте на два пятна. Такой раскол помечается как артефакт растра и сам по
себе прогон не валит — разрыв считается по частицам.
