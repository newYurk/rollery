# Что выбирать в лаборатории

Шпаргалка, чтобы не переспрашивать. Полный разбор — `sim/KINEMATICS.md`.

## Коротко: лаборатория и игра — разные программы

**Они не общий код и никогда им не были.**

| | лаборатория (`sim/`) | игра (`play/index.html`) |
|---|---|---|
| что делает | считает **настоящую физику**: частицы, контакты, MLS-MPM | мотает **спираль** по формуле |
| на чём | Python + Taichi, считает на процессоре или видеокарте | JavaScript в браузере |
| сколько идёт | минуты на один ролл | **1–8 мс**, укладывается в кадр |
| зачем | ответить, **как оно на самом деле** | показать это игроку за 16 мс |

**Порядок работы такой:**

1. в лаборатории прогоняется вопрос — «сколько витков», «как уплотняется рис», «рвётся ли нори»;
2. из прогона достаётся **число** — витки, диаметр, доля воздуха;
3. число едет **в игру** как формула или константа, с пометкой, откуда взялось;
4. в игре стоит проверка `play/checks.js`, которая держит эти числа.

Физика из лаборатории в игру **не переносится** — только её выводы. Игра не считает
частицы и считать не будет: три тысячи зёрен это 109 гигафлоп на один ролл.

## Что выбирать

| вариант | когда брать |
|---|---|
| **★ Эталон (`reference2`)** | **по умолчанию.** Победитель очной ставки 26.08. Циновка под листом и заворачивается вместе с роллом, пальцы держат начинку |
| Прежний эталон (`reference`) | первая сборка, заменена. Для новых прогонов не брать |
| Спираль · завивка | только для **сладкого рулета** — у него нет подворота |
| Спираль · посев | то же, второй кандидат; что из двух правда — вопрос к прогону |
| Лопатка | если надо проверить подворот без пальцев на начинке |
| ✗ Захват края | **не брать.** Отвергнут: источники говорят, что нори пальцами не берут |
| ✗ Первая версия | **не брать.** Историческая, циновка катится по столу — так не крутят |
| Песочница | личная копия, можно ломать |

## Чего в лаборатории пока нет

**Урамаки** — нужен шестой вариант: нори внутри, рис снаружи, циновка застелена плёнкой.
Траектория руки та же, меняются начальная укладка и контакты. Заведено как issue #3.

## Прогоны гонять через лабораторию, а не мимо

Симуляцию можно запустить и напрямую (`python sim/reference2/run.py …`), но тогда владелец
не видит ни что считается, ни кадров. **Правильно — через лабораторию:**

```
curl -s -X POST http://127.0.0.1:8770/api/run -H 'Content-Type: application/json' \
  -d '{"variant":"reference","layout":4,"frames":60,"grid":220,"particles":16000}'
```

Прогон появляется в списке, кадры видны по мере готовности. `frames` — до 60; для разбора
начала скрутки меньше 40 брать бессмысленно, иначе на всю фазу подъёма придётся один снимок.

## Запускать лабораторию только через `lab.sh`

```
sim/lab/lab.sh
```

**Не** `python serve.py`. Лаборатория запускает расчёты **тем же интерпретатором, которым
запущена сама** (`PY = sys.executable`), а Taichi стоит только в `sim/.venv`. Запустишь
системным питоном — сервер поднимется, страница откроется, кнопки будут нажиматься, и
каждый прогон упадёт с кодом 1. Симптом обманчивый: выглядит как поломка расчёта, а на
деле сломан запуск.

`lab.sh` включает окружение первой же строкой. Если нужно в фоне:

```
cd sim/lab && ../.venv/bin/python serve.py
```
