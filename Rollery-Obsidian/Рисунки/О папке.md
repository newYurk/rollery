# Рисунки

Здесь — рисунки владельца: наброски механик от руки и правки поверх скриншотов игры. Это канал
обратной связи для агента: он читает рисунок и отвечает текстом и кодом.

**Как нарисовать поверх скриншота.** Положить картинку в эту папку, вставить её в заметку
(`![[имя.png]]`), поставить курсор на вставку, ⌘P → «Excalidraw: Annotate image in Excalidraw».
Ссылка в заметке заменится ссылкой на рисунок, а рядом сам появится `имя.excalidraw.png` —
его агент и смотрит. Набросок с нуля: ⌘P → «Excalidraw: New drawing».

**Что обязательно в настройках Excalidraw** (Settings → Excalidraw):
- Saving → «Compress Excalidraw JSON in Markdown» — **выключено**: иначе подписи на рисунке хранятся
  нечитаемым блоком, и ни агент, ни git их не видят;
- Embedding… and Exporting → Export Settings → «Auto-export PNG» — **включено**;
- Basic → «Excalidraw folder», а также «Image annotation file folder» и «Crop file folder» — `Рисунки`.

**Что делает агент с рисунком — и чего не делает.** Читает, отвечает текстом и кодом. Не
перерисовывает, не «причёсывает», не удаляет и не переносит. Свои схемы рисует только текстом
(Mermaid) — сгенерированный рисунок устаревает быстрее, чем его успевают прочесть.

Генератор хранилища (`tools/obsidian-vault.py`) эту папку не трогает.
